# Notes

Use the notes tools when available:

- `note_append_daily` for quick daily log entries.
- `note_append` for a specific file under the notes root.
- `note_read`, `note_list`, `note_search` for retrieval.

Keep notes concise. Capture decisions, rationale, follow-ups, and mistakes worth not repeating. Do not store secrets.
